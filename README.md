# FontFlow - Font Preview Tool

一個快速、直觀的字體預覽工具，支援上傳 TTF、OTF、WOFF、WOFF2 字體檔案，並智能自動檢測繁簡中文、日文等多語言支援情況。

## 功能特性

✨ **快速上傳預覽** - 無需安裝字體到系統，即時在瀏覽器中預覽效果

🎨 **完整自訂選項** - 調整字體大小、文字顏色、背景顏色

📋 **文字輸入管理** - 支援自訂文字輸入和清空預覽

🔍 **智能字體分析** - 自動檢測字體對繁體中文、簡體中文、日文的適用性覆蓋率

📊 **視覺化呈現** - 進度條展示覆蓋率，顏色編碼快速判斷適用性

🛡️ **隱私保護** - 所有檔案處理均在瀏覽器本地完成，不上傳任何資料到伺服器

## 架構分析

### 高層架構流程

```
用戶界面 (App.tsx)
    ↓
[上傳字體] ──→ 檔案驗證 (MIME type + 副檔名)
    ↓
字體解析 (fontHelper.ts)
    ↓
[analyzeCompatibility()]
    ├─→ getCoverage(TC_TEST_CHARS) → 繁體中文覆蓋率
    ├─→ getCoverage(SC_TEST_CHARS) → 簡體中文覆蓋率
    └─→ getCoverage(JA_TEST_CHARS) → 日文假名覆蓋率
    ↓
[generateDescription()]
    └─→ 基於覆蓋率生成適用性結論 + emoji標籤
    ↓
FontDefinition 物件 (含coverage和description)
    ↓
React組件 (App.tsx)
    ├─→ 彩色進度條 (TC: 綠/黃/橙/紅)
    ├─→ 簡體/日文進度條 (藍/粉紅)
    ├─→ 適用性結論文字
    └─→ 標籤徽章
```

### 核心模組分析

#### 1. **App.tsx** - 主應用層

- **責任**: UI狀態管理、用戶交互、檔案上傳流程
- **狀態管理** (8個state):
  - UI控制: `fontColor`, `bgColor`, `fontSize`, `inputText`
  - 檔案狀態: `currentFont`, `isAnalyzing`, `uploadError`, `isDragActive`
- **關鍵方法**:
  - `processFont()` - 檔案上傳 → 分析 → FontFace加載
  - `handleDrop()` / `handleDrag()` - 拖曳上傳支援
  - 檔案驗證 (MIME type + 副檔名雙重檢查)
- **特性**:
  - 實時字體預覽 (background + fontColor)
  - 響應式設計 (lg:grid-cols-12)
  - 無依賴字體分析 (本地執行)

#### 2. **fontHelper.ts** - 字體分析引擎

- **核心函式**:
  ```typescript
  analyzeCompatibility(font)
    ↓
  - getCoverage(font, chars) → {count, total, percent}
  - generateDescription(coverages) → 適用性文字描述
  ```
- **測試字符集** (89個特徵字):
  - TC_TEST_CHARS: 50個常用繁體字 (含特有字、高頻字、文案用字)
  - SC_TEST_CHARS: 20個簡體特有字
  - JA_TEST_CHARS: 20個日文假名 (平假名+片假名)
- **適用性邏輯**:
  ```typescript
  TC >= 90% → ✅ 完全適用 (綠色)
  TC >= 70% → ⚠️ 大致適用 (黃色)
  TC >= 50% → ⚠️ 部分適用 (橙色)
  TC <  50% → ❌ 不建議 (紅色)
  ```
- **字體加載**: `loadFontFace()` 使用 FontFace API 動態注入

#### 3. **types.ts** - 型別定義

```typescript
FontDefinition
├─ name: string (字體名稱)
├─ family: string (CSS font-family)
├─ category: 'sans-serif'|'serif'|'display'|'handwriting'
├─ tags: ('tc'|'sc'|'en'|'ja'|'ko')[] (適用性標籤)
├─ description?: string (適用性文字結論)
├─ glyphCount?: number (字符總數)
└─ coverage?: {tc, sc, ja} (覆蓋率百分比 0-100)
```

#### 4. **Constants.ts** - 靜態資料

- `SAMPLE_TEXTS.tc` - 預設範本文本 (繁體中文)
- `FONT_LIST` - 預定義字體列表 (用於對照測試)

#### 5. **Footer.tsx** - 頁腳元件

- 隱私聲明、版權資訊
- 分離式可復用元件

#### 6. **index.css** - 全域樣式

```css
@import 'tailwindcss'; /* Tailwind v4 */
@theme {
  --color-primary: #ea580c; /* 橙色主色 */
}
```

## 字體適用性分析邏輯

### 核心設計理念

FontFlow 採用**適用性評估**而非傳統的語系分類：

- ❌ **不再問**：「這是什麼語系的字體？」
- ✅ **改為問**：「這個字體能滿足繁體中文排版需求嗎？」

### 分析流程

```
上傳字體
    ↓
測試 50 個繁體常用字 → 計算繁體覆蓋率
測試 20 個簡體特有字 → 計算簡體覆蓋率
測試 20 個日文假名 → 計算日文覆蓋率
    ↓
根據覆蓋率判斷適用性
    ↓
顯示進度條 + 結論 + 標籤
```

### 測試字符集詳解

#### 繁體中文 (50 字)

**繁體特有字** (10字): 國、體、話、寶、門、經、號、葉、說、邊

- 特色: 日本字體通常不包含這些字

**高頻常用字** (10字): 的、是、在、有、我、你、他、她、們、個

- 特色: 日常文案必需

**繁體文案常見字** (10字): 臺、灣、網、路、資、訊、設、計、產、品

- 特色: 科技、品牌用語

**其他補充字** (20字): 確保覆蓋常見詞彙

#### 簡體中文 (20 字)

国、体、话、宝、门、经、号、叶、说、边、实、这、会、后、学、机、关、开、电、车

#### 日文 (20 字)

- 平假名 (10字): あ、い、う、え、お、か、き、く、け、こ
- 片假名 (10字): ア、イ、ウ、エ、オ、カ、キ、ク、ケ、コ

### 適用性等級

| 等級     | 繁體覆蓋率 | 評估                | 顏色 | 建議     |
| -------- | ---------- | ------------------- | ---- | -------- |
| 完全適用 | 90%+       | ✅ 完全適用繁體中文 | 綠色 | 放心使用 |
| 大致適用 | 70-89%     | ⚠️ 可能缺少少數字   | 黃色 | 注意細節 |
| 部分適用 | 50-69%     | ⚠️ 建議謹慎使用     | 橙色 | 避免正文 |
| 不建議   | <50%       | ❌ 繁體支援不足     | 紅色 | 不建議   |

### 實戰案例

| 字型               | 繁體 | 簡體 | 日文 | 結論                    |
| ------------------ | ---- | ---- | ---- | ----------------------- |
| 思源黑體 TW        | 100% | 20%  | 0%   | ✅ 完全適用繁體         |
| 小塚明朝           | 85%  | 15%  | 95%  | ⚠️ 大致適用繁體，含日文 |
| 思源黑體 SC        | 20%  | 100% | 0%   | 🇨🇳 簡體中文字型         |
| 思源宋體 (Pan-CJK) | 95%  | 98%  | 90%  | ✅ 完全適用，多語言支援 |
| 某動漫字體         | 15%  | 5%   | 85%  | 🇯🇵 日文為主             |

### 為何採用此邏輯

1. **實用性** - 直接回答「能用嗎？」而非抽象分類
2. **精確性** - 50個字代表日常文案需求
3. **視覺友善** - 進度條 + 色碼快速判斷
4. **多語言參考** - 同時展示簡體/日文，方便對比

## 常見問題

**Q: 為什麼字體上傳後沒有立即顯示？**
A: 瀏覽器正在解析字體檔案並注入DOM，通常需要1-3秒。

**Q: 能否離線使用？**
A: 可以。下載後使用 `npm run build && npm run preview`，完全本地執行。

**Q: 支援哪些字體格式？**
A: TTF、OTF、WOFF、WOFF2。FontFlow通過OpenType.js解析。

**Q: 能否新增其他語言檢測？**
A: 可以。在 `fontHelper.ts` 中添加新的字符測試集。

**Q: 為什麼日文判斷閾值是50%而不是70%？**
A: 日文字體通常包含較少假名(只有70個)，70%閾值會過高。

## 常見問題

**Q: 為什麼字體上傳後沒有立即顯示？**
A: 瀏覽器正在解析字體檔案並注入DOM，通常需要1-3秒。

**Q: 能否離線使用？**
A: 可以。下載後使用 `npm run build && npm run preview`，完全本地執行。

**Q: 支援哪些字體格式？**
A: TTF、OTF、WOFF、WOFF2。FontFlow通過OpenType.js解析。

**Q: 能否新增其他語言檢測？**
A: 可以。在 `fontHelper.ts` 中添加新的字符測試集。

**Q: 為什麼日文判斷閾值是50%而不是70%？**
A: 日文字體通常包含較少假名(只有70個)，70%閾值會過高。
